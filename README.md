# مستشفى السدرة الريفي — Al-Sidra Rural Hospital (Archive 1994)

لعبة رعب واستكشاف نفسي من منظور الشخص الأول مستوحاة من أجواء **Silent Hill**، مبنية بمحرك **Three.js + Vite** معماريًا وبصريًا بالكامل ومُحسّنة خصيصًا للعمل بسلاسة على الهواتف الذكية دون استنزاف البطارية أو سخونة الجهاز.

**الرابط المباشر للّعب:** https://abdrahman20091228-ux.github.io/al-sidra-hospital/

---

## أبرز المزايا (تحديث سايلنت هيل الجذري)

- **ظلام مطبق وإضاءة بالكشاف اليدوي فقط:** لا توجد أي إنارة كهربائية عاملة داخل المستشفى المهجور أو حوله؛ ضوء قمر خافت جدًا في الغابة يتلاشى تدريجيًا إلى الصفر كلما توغلت داخل الممرات والغرف.
- **رحلة استكشاف متصلة:** تبدأ في غابة وادي الضباب بأرضية ثلاثية الأبعاد وجذور وصخور، ثم تسلك طريقًا طينيًا متعرجًا بأخاديد عجلات عميقة وبرك مياه وجسر خشبي متآكل، وصولًا إلى الواجهة المهجورة على شكل حرف U لمستشفى السدرة الريفي (دون سيارة إسعاف أو أي مظهر حديث).
- **تصميم معماري مدروس (طابقان — ١٦ قسمًا حقيقيًا، بدون متاهات عشوائية وبدون وحش حاليًا):**
  - الطابق الأول: بهو الاستقبال، الطوارئ والفرز، الصيدلية، محطة التمريض، قسم الأشعة السينية (بأفلام أشعة غير مضاءة)، المختبر الطبي، جناح التنويم، غرفة العزل ٢٠٤، غرفة العمليات الجراحية، غرفة التعقيم والدرج، المشرحة وثلاجة الموتى، ومكتب المدير والأرشيف.
  - الطابق الثاني: جناح الأطفال القديم، والغرفة ٣١٢ المغلقة (أرشيف الممرضة ندى السري).
- **خرائط ورقية قديمة ممزقة (٣ خرائط واسعة قابلة للتبديل):**
  1. خريطة الغابة والطريق الطيني المتعرج
  2. مخطط الطابق الأول (١٤ قسمًا)
  3. مخطط الطابق الثاني (جناح الأطفال والغرفة ٣١٢)
- **مكتبة خامات PBR متكاملة:** جدران جصية متقشرة بطبقتين (Dado) خالية من التكرار، معادن صدئة، ستانلس ستيل مصقول للمشرحة والعمليات، ستائر قماشية مبقعة، جلود متشققة، صناديق أرشيف، وأوراق طبية مصفرّة.
- **منظومة صوتية محيطية وتنفس للشخصية:** تنفس طبيعي، لهاث وإرهاق مرتبطان بالجري والقدرة على التحمل، نبض قلب خافت، حفيف الورق عند فتح الخريطة، رعد بعيد، صرير معادن وقطرات ماء في الممرات.
- **أداء عالٍ وموفّر لبطارية الهاتف:**
  - اختيار حد الإطارات: **30 / 45 / 60 / 90 FPS**.
  - أوضاع جودة وتوفير طاقة (`موفر بطارية` / `متوازن` / `عالي`) مع تحديد `DPR` وتخطي تحديث الظلال وإيقاف المعالجة الرسومية تمامًا عند التوقف أو فتح القوائم.
  - دمج هندسي (`GeometryBatcher` + `InstancedMesh`) وعزل مناطق (`Zone Culling`) لخفض نداءات الرسم إلى ~50–85 نداءً فقط داخل المستشفى.

## هيكلة المشروع

```text
al-sidra-hospital/
├── index.html
├── vite.config.js
├── public/textures/        # خامات PBR (Albedo + Normal + Roughness + Decals)
└── src/
    ├── main.js             # حلقة اللعبة الرئيسية وإدارة الحالة والإعدادات
    ├── styles/main.css     # واجهة المستخدم العربية وتنسيق الخريطة الورقية
    ├── core/
    │   ├── config.js       # إعدادات الأداء والبطارية وحدود FPS
    │   ├── engine.js       # محرك Three.js والكشاف اليدوي وتدرّج الظلام
    │   ├── geometry.js     # دمج المجسمات (GeometryBatcher + InstancedMesh)
    │   ├── materials.js    # مكتبة الخامات PBR واللافتات المتهالكة
    │   └── physics.js      # التصادمات المكانية والدرج
    ├── world/
    │   ├── layout.js       # المخطط المعماري للطابقين الأول والثاني
    │   ├── forest.js       # غابة وادي الضباب والطريق الطيني ثلاثي الأبعاد
    │   ├── exterior.js     # واجهة المستشفى المهجور والسور والبوابة
    │   ├── hospital.js     # الهيكل الداخلي والجدران والأسقف والدرج
    │   └── props.js        # المجسمات الداخلية وفوضى الهجر والتفاصيل الطبية
    ├── systems/
    │   ├── player.js       # التحكم (حاسوب + لمس للهاتف) وحركة الكاميرا واللهاث
    │   ├── audio.js        # الصوتيات الإجرائية والتنفس والنبض والمحيط
    │   ├── mapUI.js        # نظام الخرائط الورقية الممزقة الثلاث
    │   ├── hud.js          # الواجهة والأزرار ومؤشرات الأداء والبطارية
    │   └── story.js        # المهام الـ ٨ والملفات الأرشيفية ودردشة البث
    └── utils/
        └── math.js         # التضاريس العضوية ومنحنى الطريق الطيني
```
